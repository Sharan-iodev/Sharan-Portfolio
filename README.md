## 🚀 Overview

A modern, high-performance developer portfolio built with **React**, **Vite**, and **custom modern CSS**. Features dark-mode aesthetics, glassmorphism, animated terminal CLI, PDF resume preview/download, and project showcases.

### ✨ Key Features
- **Hero & Profile Showcase**: High-res cutout portrait of Sharan with dynamic ambient halo and floating credential pills.
- **Interactive CLI Terminal**: Type real commands (`help`, `skills`, `projects`, `education`, `contact`, `resume`, `hire`) or use quick chips.
- **Projects Showcase**: Interactive feature breakdown for **NexusPanel** and **RoleRadar** with simulated UI telemetry widgets.
- **Academics & CGPA**: Detailed academic breakdown (Overall: **8.68 CGPA**, Sem 2: **9.02 CGPA**) at TSEC Mumbai.
- **Direct PDF Resume Modal**: In-browser PDF preview with confetti celebration and one-click download.
- **Contact Panel**: Direct inquiry form with pre-filled `mailto` integration and one-click email copying.

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
Generates production-optimized static files in the `dist/` directory.

### 4. Preview Production Build
```bash
npm run preview
```
